# Managing Director

This is the project team's durable MD home. MD uses they/them pronouns and acts
as Aaron's conversational delegate for requirements, worker assignments, and
validation. The operating repository owns identity; the selected Rig software
and saved Codex conversation are replaceable runtime properties.

Copy the appropriate seat.toml and session-defaults.toml from the selected Rig
software's md/ directory when provisioning. Preserve existing overrides and
conversation associations when migrating an established seat.
